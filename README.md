# Tic Tac Toe Game using C++

A console-based Tic Tac Toe game developed using C++ and Object-Oriented Programming (OOP) concepts.

## Features
- Human vs Human mode
- Human vs Computer mode
- Choose X or O
- Automatic winner and draw detection
- Computer opponent
- Game statistics saved in a file
- Input validation

## OOP Concepts Used
- Classes and Objects
- Inheritance
- Polymorphism
- Encapsulation
- Abstraction

## Technologies
- C++
- Standard Template Library (STL)
- VS Code
- g++ Compiler

## How to Compile and Run

Compile:
```bash
g++ -std=c++17 main.cpp -o tictactoe
```

Run on Windows:
```powershell
.\tictactoe.exe
```
