C++ Object-Oriented Programming Project

Developed as an Individual College Project

About the Project

Tic Tac Toe is a two-player strategy game developed using C++. This project demonstrates important Object-Oriented Programming concepts through an interactive console-based game.

Features

  • Human vs Human mode
  • Human vs Computer mode
  • Choose X or O
  • Automatic winner detection
  • Draw detection
  • Computer opponent
  • Game statistics

OOP Concepts Used

  • Classes and Objects
  • Inheritance
  • Polymorphism
  • Encapsulation
  • Abstraction

Technologies

C++ | STL | GitHub
